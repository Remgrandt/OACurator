# OA Curator 0.5.1

OA Curator 0.5.1 fixes a Collection-opening error introduced in 0.5.0. Older Collection folders can now upgrade to OAA 1.0 when a local attachment's saved file size is out of date.

- Fix the upgrade failure reported as "Declared file size does not match embedded bytes" when a local file has changed since its metadata was saved.
- Preserve original scans and manifest metadata during the upgrade, with the existing private backup and recovery behavior.
- Continue to check file sizes strictly in `.oaa` ZIP archives. New exports record the sizes of the files actually included and validate the finished archive.

After installing this update, reopen the affected Collection. No manual manifest edits are needed for this error.
